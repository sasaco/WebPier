# WebPier 計算書の体裁契約（GridLayoutPdf 0.2.0 の共通グリッド）

2026-10-21 に、見本の位置に合わせた 0.12pt の格子から、GridLayoutPdf の共通グリッドへ移した（計画 `.claude/docs/plans/glp-0.2.0-grid.md`）。WebPier が組む頁は、同じものを方眼Excel（`export/<stem>.xlsx`）にも書く。そのため位置はすべてマスの数で持ち、pt の座標を書かない。

見本 `.claude/docs/Example橋脚/output` は、今も帳票の構成・文言・式の書き方・表の形の基準である。ただし、位置（X・行送り・罫線の太さ）の基準ではなくなった。見本から測った値（`tests/fixtures/reporting/appearance`、測定器 `scripts/reporting_appearance.py`、`tests/reporting/test_report_appearance.py`）は、見本の記録として残す。新しい PDF との照合には使わない。

## 版面とマス

- A4 縦、GridLayoutPdf の `A4_PORTRAIT_REFERENCE`（原点 x 50.88、y 54.598、マスは 16.08 × 15.48pt、30列 × 47行）。`webpier/reporting/styles.py` の `report_profile()`。
- 位置は本文の左端からの列の数、高さは行の数で持つ（`styles.count`・`columns_pt`・`rows_pt`・`column_x`）。図の枠は、図を覆う最小のマスの数（`columns_for`・`rows_for`）にする。図の中の線の太さと座標は pt のままでよい。
- 頁番号は印刷しない（見本にも Example2 にもない）。

## 書体

- 本文は MS明朝 10pt、見出しは MSゴシック 10pt、添字は 6.5pt（下付きは 1.92pt 下、上付きは 4.92pt 上）。図題は MS Pゴシック 10pt、外形寸法は Calibri 8pt。
- 書体は名前で引く（`"MS Mincho"`・`"MS Gothic"`・`"MS PGothic"`・`"Calibri"`。GridLayoutPdf FR-024）。書体がなければ生成を停止する。`webpier/reporting/fonts.py` の `font_files()` が名前から解決したファイルを、実装の同一性（`dependency_hashes`）に入れる。
- 字を縮めない・伸ばさない。0.5pt 刻みでない大きさは使えない（見本の 9.9pt・8.9pt はやめた）。

## 行と空き行

- 本文・式・数式行は、1行が1グリッド行。`Leading(…, 1)` は厳格で、1行を超える行は `LayoutOverflowError` になる。
- 見出しの前後は空き1行（基線の差は2行）。見出しが続いても空き行を重ねない。
- まとまり（記号式の組、「ここに、」の定義、「・長期」とその式など）の間は空き1行。表・図の前後も空き1行。表の題と表の間は空けない。
- 頁頭に来た空き行は捨てる（`spacer()`）。空き行は `blank(out)` で足し、二重にしない。

## 見出しと本文の列

| 役割 | 列 |
|---|---:|
| 章 | 0 |
| 節 | 1 |
| 項 | 2 |
| 小項 | 3 |
| 本文・「・長期」などの細目 | 4 |
| 字下げ | 5 |

0500 も他の帳票と同じ列にした（見本では 0500 だけ章が右にずれていた）。見出しの出典【…】は見出しと同じ行で、列18から書く。見出しが長ければ、全角1字以上空けて入る最小の列から書く。出典が30列に入らなければ `LayoutOverflowError` にする（`document.heading`）。

## 式

- 代入式の右辺の数値・演算子は、GridLayoutPdf のグリッドの項の列（`EquationGroup(term_columns="grid")`、`equations.terms`）に置く。各項は整数の列を占め、数値はセルの余白（2.4pt）を残して列の境目で右揃え、演算子は中央揃えにする。`"("`…`")"` は1項にまとめ、括弧の中で折り返さない。
- 等号・結果の等号は、その列の手前の境目に送りの中心を置く。結果は列の境目で右揃え、単位はその次の列から書く。境目は厳密に増える。
- 項が列に入らない式は、通常の折り返しに退避しない。`LayoutOverflowError` になるので、アンカーを見直すか式を分ける。結果の等号まで右辺が入らない式は、結果が次の行の結果の列に回る（GridLayoutPdf の決まり）。
- 連続する式は1つの `equation_group` に入れる。形（列数と揃えの並び）の同じ式は、行をまたいで項の列を共有する。形の違う式は別の群（`Stack` の子）になる。群に加えると項が列に入らなくなる式や、行が増える式は、群に加えない。
- 式ごとの「次と離さない」（`keep`）があれば、群の境目のうち、次と離してよい式の後でだけ改頁する。
- 式の左のことば（「断面積」など）は `Equation(label=…)` で、群で共有するラベルの列に置く。
- 分数は横書き「a/b」（`equations.over`）。積み分数と、分子の上付きは使わない。
- 「ここに、」の定義は、記号を右揃えにして全角コロンの列をそろえる。「(= 値 単位)」も列にそろえる（`equations.definitions`）。
- 入力票の記号（B1〜B9、H1〜H6、W3〜W9、df1、df2）は印刷しない。風荷重の W1/W2 は設計記号なので使ってよい。

|---|---|---|
| 0610・0620・0710・0720・照査系（`frame_report`） | ことば4、＝11／22／26／27 | ：8（0610・0620 の Δh は9、照査系は10） |

## 表

- 列幅はマスの数、行高は行の数（既定1行）。表の左端の列と列幅の合計が30を超えない。入らない表は左へ寄せ、列の割り振りを見直す。それでも入らなければ、表を分ける（0610・0620 の組合せ係数の表は、組合せ1つに2列を当て、要求性能の変わり目で分ける）か、回す（0900 の組合せ表は縦横を入れ替えた局所グリッドで90度回す）。
- 罫線は外枠が中（1pt）、内側が極細（0.25pt）（`tables.table`、`TableBorders`）。外枠は表の内側に引く。0610/0620 系の「鉛直力・アーム・モーメント」の小表は開いた表で、外枠・縦罫・見出しの下の線を引かず、「合計」の上に中の線を1本だけ引く。
- セルの字は境目から左右3pt 離す（`tables.CELL_PADDING`。Excel の余白 2.4pt と、中の線の半分）。縦書きのセルは `tables.VerticalLabel`。
- `frame_report` の1行の本文のセルは、行で共通の基線に置く（`CELL_BASELINE`）。添字のある「起点側 R_B」も、同じ行の数値と同じ基線になる。見出しのセルは中央揃えにする（上付きの「N/mm²」が入るため）。

## 方眼Excel

- 各段階の `grid_documents`（`render` と同じ文書。他のプログラムの頁を除く）を、`webpier/reporting/workbook.py` が `render_xlsx(strict=True)` で1冊1シートに書く。ずらしや図形への切替えが1件でもあれば書かず、生成を止める。0711・0721 は Aggre-SE の帳票そのものなので、方眼Excel を出さない。
- 列の境目の手前で終わる行は、Excel の印刷で最後の1字が欠けることがある（`texts_clipped`、GridLayoutPdf で受け入れ済みの制限）。避けられるときは1マス空けるか、行を分ける。
- 先頭の全角空白で字下げしない（Excel で位置がずれる）。字下げは列（`left=`）で行う。
