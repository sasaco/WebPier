## 結論と前の調査の訂正

Df・γ2は、今回の見本とP7の地盤条件から計算できる。独立した必須手入力欄が必要という初期調査の結論を訂正する。0500にγ2という結果キーがないことと、その算出に必要な入力がないことは別である。

P7では、同一実行の0500地盤値と0710が採用する平水位から **Df=4.700 m、γ2=12.2553191489… kN/m³** となる。見本同様に小数第1位をNDU採用値とする案では **12.3 kN/m³**。計算前後の値と丸め規則を付帯情報に残す。見本の値3.78、11.6をそのままコピーするものではない。

1. [04_地盤のモデル化.pdf](../../../.claude/docs/Example橋脚2/04_地盤のモデル化.pdf) 1頁の表層厚は3.780 m、湿潤単位体積重量18.0、水中9.0 kN/m³。支持層は湿潤19.0、水中10.0。

   `γe2(平水位) = (1.080 × 18.0 + 2.700 × 9.0) / 3.780 = 11.6 kN/m³`

   丸め前は11.5714285714…。高水位は9.0、低水位は18.0。3頁の浮力計算も高水位3.78、平水位2.70、低水位0.00を基礎底面からの高さとして使う。30頁の支持照査表でもDf=3.780、平水位γe2=11.6を確認した。

## P7へ同じ手順を適用

根拠は [0500_直接基礎.pdf](../../.././output/0500_直接基礎.pdf) 1頁、現 [input.json](../../.././pre/input.json)、同じ入力からの計算コード。

| 項目 | P7の入力・値 |
|---|---|
| 表層厚 | 4.700 m |
| フーチング高さ | H5=0、H6=2.7 m |
| 土被り | df1=df2=2.0 m |
| 平水位（底面起算） | hw2=2.7 m |
| 表層の湿潤／水中単位体積重量 | 18.0／8.0 kN/m³ |
| 支持層の水中単位体積重量 | 10.0 kN/m³ |

`Df = H6 + H5 + min(df1, df2) = 2.7 + 0 + 2.0 = 4.700 m`

`水中区間 = 2.700 m、湿潤区間 = 4.700 − 2.700 = 2.000 m`

`γ2 = (2.000 × 18.0 + 2.700 × 8.0) / 4.700 = 57.6 / 4.7 = 12.2553191489… kN/m³`

見本と同じ小数第1位の採用案は12.3。γ1は水面より下にある支持層の10.0。P7の3.78は高水位hw1でありDfではない。高水位を使った検算値は `(0.92×18 + 3.78×8)/4.7 = 9.9574468085…` だが、0710/NDUの平水位ケースへ混用しない。

コード上の追跡:

- `pier_design/input_formulas.py:94–110`: 表層厚 `H6+H5+MIN(df1,df2)`。
- `pier_design/inputs.py:81–166`、`calculator.py:127–159`: 同一実行の地層・支持層・表層厚根拠を0500結果へ渡す。
- `pier_design/reaction_weights.py:322–329`: hwを底面起算で使う浸水体積式。
- `pier_design/seismic_longitudinal_calculator.py:219–226`: 0710が `0610.vertical.water.normal` を使う根拠。

## 出力機能への反映案

- Df・γ2の手入力フォーム追加をやめ、既存入力と同一実行の0500/0710から算出する。原本PDFや保存済み0500 JSONは実行時に読み戻さない。
- 導出結果に入力パス、水位ケース、区間長、単位体積重量、式、丸め前値、NDU採用値を記録する。
- 初期対応は今回確認した一つの表層＋支持層、フーチング底面が支持層上面、同一土被り、Df>0かつ0<hw2<Dfに限定する。別地層構成、傾斜土被り、根入れ評価の別条件を推測で処理しない。
- 土被り差・表層厚と寸法式の差は1e-9 m以内を数値上の同値とし、元値・差を記録する。対応条件を先に検証し、水中区間hw2、湿潤区間Df−hw2として算出する。水位0/Dfの端点、底面以下、地表超過は初期NDU出力では拒否し、clampで通さない。Df=0、入力不足・非有限値・不整合も明示エラーとする。
- 見本3.78/11.6の再現、P7 4.7/12.3、表層水中重量9→8の差、平水位と高水位の取り違えを独立期待値で検証する。

これは入力導出の確認であり、JRSNAP解析結果・支持性能の再照査ではない。
