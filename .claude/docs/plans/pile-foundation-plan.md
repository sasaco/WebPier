# 杭基礎への対応（計画）

owner 2026-10-23。杭基礎の橋脚を計算できるようにする。

1. 0500 地盤のモデル化を、杭基礎では SOIL-JR の出力にする。
2. 0612・0622 基礎の照査を杭基礎用にする。
3. 0800 フーチングを杭基礎用にする。

まず SOIL-JR に要る入力をアプリに入れる設計をする（この文書の「入力の設計」）。杭基礎の地盤のモデル化を SOIL-JR に任せる理由は ADR-0013、決定一覧では決定80。用語は CONTEXT.md の「地盤の層」「杭頭より上の地盤」「上載土」。

## 調べたこと

- SOIL-JR の入力 .sdt の全項目：スキル structural-jrsnap-soil（`references/sdt-pile.md`）と、2026-10-23 にソースから作った項目対応表（**Ver.5.3-L01体験版2**、`Common.cs` の `DataFileWrite`/`DataFileRead`、`frmInputData.cs`、`Check.cs`、`CalcSub.cs`）。使うのは 5.2-L03（決定13）で、書式の違いは決定13 に書いた。要点（5.3 で確かめたもの。5.2 でも確かめ直す）：
  - 1つの .sdt で両方向を計算する（検討方向の欄は隠れていて、.sdc に橋軸・直角の両方が出る）。
  - 地盤は、上載土の行（G.L.〜杭頭）＋杭頭から下の層（層厚の合計＝杭長−突出長、20層まで）＋任意の杭先端の行。層は 層厚・種別（砂質土・粘性土・砂礫）・N（整数）・C・φ・γ・γ'・Ex・ρgE・γgE・Ed（＝round(Ex·ρgE/γgE)、画面が求めて保存し、読込で計算し直さない）・qsuk の算定方法と直接入力の値。
  - A・I、Lm・Ln、杭の配置の行と K_FLG、地盤抵抗係数の6行と ρgby・ρgbu・ρgsy・ρgsu は、画面が求めて保存する値で、書く側が同じ規則で書く。
  - SOIL-JR はコマンドライン引数を受け取らない。帳票は ComponentOne のプレビューから印刷か保存（HTML・XPS・RTF・Text・Excel など）だけ。
- 見本：Example橋脚4（R5 の設計計算例、鋼管ソイルセメント杭、I-4.3.2 地盤の諸数値、III-1.4 地盤のモデル化、III-3.3 基礎構造物の安定）、元Excel `Example橋脚/0510_杭基礎.xls`（場所打ち杭）、SOIL-JR の見本 `Batch/tests/JRSNAP_Ver5.3-L01体験版2/01_サンプル(V53)：RC橋脚L：PHC/`（場所打ち杭 3×3 中抜き）。

## 入力の設計（決めたこと）

1. **杭種・工法は場所打ち杭と鋼管ソイルセメント杭**（owner）。場所打ち杭は元Excel 0510・SOIL-JR の見本、鋼管ソイルセメント杭は Example橋脚4 で確かめる。ほかの杭種は選択肢を足して増やせる形にする。
2. **地盤の層は直接基礎と同じ 地盤データ.層 を G.L. から持つ**（owner）。最後の層は下に続く。WebPier がフーチング底面（Df）と杭先端（Df＋杭長）で切って SOIL-JR の行を作る。杭頭より上の地盤（SOIL-JR の上載土の行）の γ・γ' は、底面より上の層を水位より上・下の厚さで重み付けして求め、底面での土かぶり圧を地盤の層と同じにする。層を人が杭の区間に合わせて切り直さない。
3. **層の強度・変形は設計用値**（owner）。`一軸圧縮強度_qu` を `粘着力_c`（設計用値）に替え、`変形係数_Ed` はそのまま。SOIL-JR には Ex＝Ed、ρgE＝1.00、γgE＝1.0 と書く。直接基礎も qu の代わりに c を使う（0500 の地盤の表は c の列、決定63 の「qu の空欄は 0」は c について読み替える）。

4. **杭先端の行は入力しない**（owner）。SOIL-JR に杭先端の行を書かず、先端の支持力は杭先端の深さにある層の値（代表の N）で求めさせる。既知の差：Example橋脚4 は先端支持層の行（N＝14、杭先端から下方 3D の最小 N）を使うので、先端の支持力の値は合わない（層の N＝22）。
5. **杭の諸元**（owner）。`下部構造.杭種` を `下部構造.基礎形式`（直接基礎・場所打ち杭・鋼管ソイルセメント杭）にし、杭の項目を1つのまとまりにする。
   - 共通：杭長 L（m 3桁）、杭の単位体積重量（kN/m3 1桁、SOIL-JR の K_Ganma。予約項目の `単位体積重量.杭.鉛直重量`・`慣性力` はこれ1つに替える。地震時の慣性力の扱いは杭基礎の 0710・0720 で決める）。
   - 場所打ち杭：杭径 D（m 3桁、D1）、杭のコンクリートの f'ck（Ec は決定25 の表で求める）、施工条件（自然泥水・安定液使用。予約項目の元Excelの4つの選択肢は SOIL-JR の2つに替える）。工法は場所打ち杭（K_KOHO 1）で、先端強化型（8）は扱わない。
   - 鋼管ソイルセメント杭（K_KIND 5、K_KOHO 7）：ソイルセメント径 Dsc（m 3桁、D1）、鋼管外径 Dsp（m 3桁、D2）、鋼管厚 t（mm 1桁、t1。腐食代を含む厚さ）、腐食代 c（mm 1桁）。
   - 導く値：Es＝200.0 kN/mm²（鋼管、プログラムの定数）、突出長＝0、支持層への最小根入れ＝SOIL-JR の自動の規則（D1。先端の層が粘性土なら D1/2）、平水位（G.L. から下向き）＝Df − hw2、A・I は SOIL-JR の式（場所打ち杭 A＝πD²/4・I＝πD⁴/64、鋼管ソイルセメント杭 A＝πDsc²/4・I＝π{(Dsp−2c)⁴−(Dsp−2t)⁴}/64、c・t は m に直す）。Example橋脚4 の I＝0.00318 は t＝18 mm・c＝1 mm（有効肉厚 17 mm）で合う。
6. **杭の配置は、方向ごとの杭列の位置の並び＋格子／千鳥＋抜く杭**（owner。CONTEXT.md「杭の配置」「千鳥配置」）。位置はフーチングの中心からの符号付きの距離（m 3桁、骨組の x と同じ向き）。抜く杭は（線路方向の列番号, 直角方向の列番号）。列ごとの本数・間隔、SOIL-JR の行（本数, 1列目からの距離）、K_FLG（中抜き・不等間隔・千鳥で 1）、Lm・Ln（格子は間隔、千鳥は SOIL-JR の 1.5 の規則）、.sdt の抜く杭の行（直角の番号, 橋軸の番号の順）は導く。千鳥は両方向とも奇数列で、番号の和が偶数の位置に杭があり、杭のない位置は抜けない。

7. **SOIL-JR の基本条件は入力しない**（owner。決定13 で 5.2 に合わせて改めた：疎密・単杭/群杭は 5.3 だけの項目）。WebPier が決める：フーチングあり、前面抵抗は考慮しない（Example橋脚4 と同じ。.sdt のフーチング形状の行は値を持たない）、換算抵抗幅 L＝√n·D の n は杭の総本数。L2 地震時の杭頭から 1/β までの杭周面の鉛直せん断地盤抵抗の扱い（5.3 の J_BaneFlg）も 5.2 にはない。
8. **液状化は層ごとの De で扱う**（owner。決定13 で 5.2 に合わせ、De は層ごとに1つ）。地盤の層に De（小数3桁、0〜1）を足す。空欄は「その層は液状化しない」という入力そのもので 1 と読む（決定62 の雪荷重と同じ考え方）。杭の区間の層のどれかの De が 1 未満のときだけ SOIL-JR の液状化の考慮をオンにし、液状化時用の .sdr・.sdcl も作る。De は層を切っても引き継ぐ。液状化時用の結果を使う側（0711・0721 の液状化時の照査など）の扱いは、杭基礎の地震時の段階で決める。
9. **基準周面支持力度 qsuk の算定方法は土質区分で決める**（owner）。砂質土・砂礫は N値より、粘性土は粘着力 c より（SOIL-JR の既定、Example橋脚4 表 1.4.14 と同じ）。杭先端が粘性土の基準先端支持力度 qbuk も粘着力 c より。直接入力は扱わない。

10. **杭の区間の層の値の要否**（owner）。杭の区間（フーチング底面〜杭先端）の層：砂質土・砂礫は N値（1以上）・γ・γ'・Ed・φd が必須（0 より大）で c の空欄は 0、粘性土は N値・γ・γ'・Ed・c が必須で φd の空欄は 0、砂質土と粘性土の互層は入力エラー（SOIL-JR の地盤種別は 砂質土・粘性土・砂礫 だけ）。杭頭より上の地盤は γ・γ' だけを使い（土質区分は問わない）、重み付けした値を小数1桁に丸めて書く。直接基礎はいまのまま（支持層の c の空欄は 0、決定63 を c に読み替え）。
11. **入力は最上位の `杭基礎` にまとめ、エディタに専用のページを置く**（owner）。`下部構造.基礎形式` だけを `下部構造` に残す。`杭基礎` は 杭長・杭の単位体積重量・場所打ち杭（杭径・f'ck・施工条件）・鋼管ソイルセメント杭（Dsc・Dsp・t・腐食代）・配置（格子/千鳥・線路方向の列の位置・線路直角方向の列の位置・抜く杭）。予約項目の `下部構造.杭種`・`場所打ち杭の施工条件`・`杭の配置`・`単位体積重量.杭` は消す（後方互換は作らない）。基礎形式が直接基礎のときは `杭基礎` を使わず、選んでいない杭種の欄も使わない（形式と桁だけを検査し、エディタは選んだ基礎形式の欄だけを出す）。ページは 地盤データ の次に置き、後ろのページの番号を1つずつ送る。地盤の層の c・De は 地盤データ の地層一覧の列。
12. **杭基礎の 0500 は SOIL-JR の帳票そのもの、名前は `output/0500_杭基礎.pdf`**（owner）。決定56（Aggre-SE の report.pdf）と同じく、SOIL-JR が組んだ帳票（印刷プレビューの全項目）をバイト列のまま 0500 にし、WebPier は頁も見出しも足さない。直接基礎は `0500_直接基礎.pdf` のまま。.sdt・.sdr・.sdc（液状化時用も）は付帯JSON付きで post/ に出す。杭頭より上の地盤の γ・γ' の重み付けや層の切り分けは帳票には出ない（入力一覧に結果の値が出る）。
13. **SOIL-JR は 5.2-L03（基礎標準 H24）を使う**（owner）。WebPier の JRSNAP（5.2-L03）と基準をそろえ、Example橋脚4（H24 の係数：鋼管ソイルセメント杭の ρgty 0.9・ρgtu 1.3、III-14。限界値の名前：長期支持性能・短期支持性能・残留変位、III-156）と合わせる。5.3-L01体験版2 は「基礎構造物（令和〇年〇月）準拠」の下書きの基準で、既定値が違う（ρgby 0.65 など）。.sdt は 5.2 の書式（`Ver.5.2.3.T08`）で書く。5.2 の書式：基本条件は `1,1` の次が n だけ（疎密・単杭/群杭の行がない）、フーチング形状は5項目、地層の後ろは qbuk の行と S_rfkKind の行だけ（J_BaneFlg がない）、●地盤抵抗係数 は5行と `G_User_Rgtu, G_User_Rgfu, フラグ` の1行、●液状化の低減係数 は ` 0 `（フラグ）と `番号,De` の行。5.2 の SOIL-JR.exe は 鋼管ソイルセメント杭（ソイルセメント径 D1）を持つ（実行ファイルの文字列で確認）。5.2 のソースはインストール先にないので、項目対応表は 5.2 の見本、5.3 の読込の古い書式の分岐、実アプリで作り直す。
14. **SOIL-JR は JRSNAPHeadless の runner の命令で動かす**（owner）。ReportHost（S_DataCheck・S_LoadPicture と同じ、別のアプリケーションドメインで画面を隠して操る、ライセンス引数、ComponentOne の PDF 出力、TEMP の切り分け）で SOIL-JR を動かし、.sdt を受けて .sdr・.sdc（液状化時用も）と帳票の PDF（全項目）を返す。protocol v1 の envelope、環境変数は既存の `STRUCTURAL_MCP_JRSNAP_RUNNER`。WebPier は .sdt を書いて runner を呼ぶだけ。runner がないときは 0500（杭基礎）を含む生成を止める。

## 既知の差

- 杭先端の行を書かない（決定4）ので、Example橋脚4 の先端の支持力（N＝14）とは合わない。
- 杭頭より上の地盤の γ・γ' は小数1桁に丸めるので、フーチング底面での土かぶり圧は地盤の層からの値と丸めの分だけ違う。
