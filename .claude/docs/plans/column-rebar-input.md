### Purpose

橋脚自動設計アプリの柱配筋を、径・片面本数・ピッチ・かぶりから自動配置し、断面図を見ながら必要な位置だけ修正できるようにする。`./pre/input.json` の柱配筋を指定原本に合わせ、同じ76本の主鉄筋から線路方向11段・直角方向31段の鉄筋配置表を再現する。

ユーザー確認済み:

1. 柱専用画面を設け、必要ならJSONも整理する。
2. 基本入力 → 自動配置 → 必要箇所だけ詳細修正、の流れとする。
3. WebPierの実入力も見本の柱配筋に合わせる。
4. 純かぶりから芯かぶりを自動計算し、個別に芯位置を直接指定できるようにする。
5. 詳細修正後に基本条件を変えても修正済み配置を保持し、「再配置」で新旧を確認してから置き換える。

#### 画面と操作

柱を選ぶと専用画面を表示する。基本配筋、帯鉄筋、詳細修正を整理し、断面図と方向別確認表を常に参照できる構成とする。狭い画面では確認表の方向切替・スクロールを使い、主要入力・保存・再配置を隠さない。

| 主筋の基本行 | 線路方向用（上下の面）／直角方向用（左右の面）、材質、径、配筋段、片面本数、配列方法、ピッチ |
| かぶり | 共通の純かぶり、行ごとの自動／指定、算定された芯かぶり、指定値。自動に必要な不足項目を具体的に表示 |
| 帯鉄筋 | 現在断面の外巻き帯筋径、方向別の径・合計有効本数・間隔・材質。高さ区間は詳細項目で保持 |

| 再配置 | 修正済み配置と新しい自動配置を別々に表示。本数・径別本数・移動位置・生成エラーを確認し、適用／取消 |

表示名「片面本数」と断面全体の総本数を区別する。旧画面の「基本配置をコピーしたが使用元は切り替わらない」という手順は柱専用画面から除く。

#### 配置規則

面に直交する芯かぶりと、面内の鉄筋の並べ方を分離する。新しい配列条件は`main_rows`内の`distribution`へ保持し、寸法はmmとする。

1. **区間を等分**: 既存の両端を含む／含めない規則を保持。旧入力はこの挙動を変えない。新規則では両側の端部芯距離`edge_center_mm`を法線方向の芯かぶりとは別に指定する。
2. **指定ピッチで中央揃え**: 指定本数nをピッチpで断面中央に配置。開始位置は `(面内寸法 - (n-1)*p)/2`。
3. **両端筋＋内部を指定ピッチ**: 両端共通の端部芯距離`edge_center_mm`に2本、残りn-2本をその区間の中央にピッチpで配置。端部芯距離は面内の側端面からの距離として指定し、法線方向の芯かぶりから黙示流用しない。WebPierは108の一入力から108/4392を得る。左右非対称な例外は詳細位置で扱う。

モードごとに必要項目・有効項目を明示する。0本は配筋なしとして値を保持、1本は等分・中央揃えで中央、両端筋モードの正の本数は2本以上（2本なら内部なしでピッチ不要、3本以上は正のピッチ必須）。両端間隔の逆転、内部筋のはみ出し、同径・同実効材質の異方向隅角共有以外の重複・重なりを拒否する。既存の最大本数制限を生成前に適用する。不完全な行は保存可能だが、未生成部分と不足値を表示して「正常な全配置」と区別する。

多段は既存の純かぶり・外帯筋径・径・段間のあきによる芯計算を維持する。自動値と指定値を混同しない。原本のD19=102 mmのために自動値101.5 mmを丸める規則は追加しない。

#### 帯鉄筋の意味と保存

柱だけに小さな`column_hoops`を追加する。

```json
{
  "enclosing_diameter_mm": 22,
  "direction_rows": [
    {"direction": "線路", "diameter_mm": 22, "material": null,
     "effective_legs": 10, "pitch_mm": 150, "start_mm": null, "end_mm": null},
    {"direction": "直角", "diameter_mm": 22, "material": null,
     "effective_legs": 6, "pitch_mm": 150, "start_mm": null, "end_mm": null}
  ]
}
```

外帯筋径は現在入力中の柱断面の芯かぶり算定用。方向別行は外側・内側を含む合計であり、10/6を5/3組や内側8/4本へ変換しない。形状を本数から推測しない。外帯筋位置を描く場合は模式図であることを明示する。

`column_hoops`不在なら旧`band_rows`を使用し、存在すれば新方式を使用する。旧行と新行を加算しない。nullや不正形ならエラーとし、旧方式へ黙示フォールバックしない。新方式への切替は明示操作とし、旧データは失わず保持する。旧入力から曖昧な外／内合計や高さ別径を自動合成しない。

区間は柱下端からの開始・終了位置を保持する。未指定は未指定であり、全高と読み替えない。異なる外帯筋径がある旧入力を共通径へ潰さず、現在断面の径を指定するか芯かぶりを直接指定する。高さ別の自動断面切替は今回追加しない。

#### 保存互換性と詳細修正

- 新規則・`column_hoops`・新しい生成元情報を使用して保存するとき、`鉄筋.version=2`にする。1/2を読めるようにし、未対応versionは拒否する。未知の新規則は旧規則に読み替えない。
- version=1のデータは表示や無変更保存だけで移行しない。version=2の後に梁・フーチングを保存しても2を維持する。未編集のキー、欠落/null/0、未知拡張、非対象部材を保持する。
- `main_rows`、`manual_positions`、`position_mode`、既存共通材料を再利用する。UIの「自動配置」は基本、「詳細修正」は指定に対応する。循環importを避け、柱純粋処理と共通検証の依存方向を固定する。
- 自動配置中は基本条件から生成。初めて位置を詳細編集するときは現在の完成した配置をコピーし、コピー・編集・使用元切替を一括で確定する。不完全配置を完全な編集用配置としてコピーしない。
- 詳細配置の生成時点の寸法・配置規則・材料・外帯筋条件・生成規則版を`manual_basis`に保持し、現在条件と比較する。新たに生成する詳細位置は解決した材質も保存し、材質nullが残る場合は未確定値として扱い、基本材質変更によって動的に変えない。`manual_basis`のない既存指定XYは、ルートがv2になっても従来の材質継承を保持し、「生成元不明」と表示する。未知の生成規則版は黙示更新しない。
- 詳細修正中の基本条件変更は、使用中の詳細位置を上書きせず「基本条件の変更は未反映」と表示する。寸法変更も位置を自動拡大・縮小せず、現在寸法に対する検証を行う。
- 再配置の適用は候補配置の検証後に一括で行い、詳細位置と生成元情報を置き換える。使用元は詳細修正のままとし、次の基本条件変更でも位置が無断変更されないようにする。取消・エラーでは詳細位置、基本条件、使用元を変更しない。
- 自動配置へ戻す場合は別の明示操作とし、現在の自動配置との比較を経て切り替える。詳細位置は非アクティブな退避値として保持し、直接上書きしない。詳細への復帰も明示操作とし、退避値と新規コピーを無言で取り違えない。
- 再配置確認中は元入力を変更不可とする。万一入力が変わっていた場合は候補の適用を拒否し、再生成を求める。保存・画面切替時は編集中セルを確定し、候補document全体を検証してから反映する。

### Risks & Considerations

- **2方向の不一致**: 入力の正本は一つの物理配筋。独立した方向表の編集を禁止し、全位置・径別集計まで照合する。
- **隠れたデータ変更**: 旧方式を等間隔の新方式へ黙示移行しない。version切替と配筋値の訂正は明示操作。WebPier更新だけが今回の実値変更対象。
- **帯筋の意味の混同**: 有効本数を組数や内側形状へ逆算しない。高さ未指定を全高へ補完しない。
- **自動芯の未確定**: 外帯筋径の不足・多段の不足を具体的に表示し、不足値を推測しない。D19=102は指定値として守る。
- **再配置での消失**: 修正保持、再読込、取消、入力変更後の古い候補を状態遷移試験で保証する。
- **共通UIへの影響**: 柱固有部分を分離し、共通保存・材料参照・梁・フーチングを回帰確認する。循環importや二重の方向集計を作らない。
- **環境と並行差分**: 多数の未コミット変更がある。対象行だけ編集し、既存作業を巻き戻さない。既存lockfile/ローカルGridLayoutPdfの作業は触らず、利用可能なプロジェクト仮想環境で検証する。
- **スコープ**: 配筋入力の整合確認は構造耐力照査ではない。新しい計算書・ソルバー連携を完了したように表示しない。
