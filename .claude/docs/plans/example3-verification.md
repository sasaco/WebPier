## 決めたこと（owner 2026-10-22、grill-with-docs）

1. **第1段の範囲**：WebPier が自分で計算する段階と骨組解析の設計応答値。0500・0600・0610・0620・0612・0622、骨組の断面力と反力（Ⅱ-2.4・2.5、Ⅱ-4.4・4.5）、地盤のモデル化（Ⅲ-2.4）。Capacita（0611/0621・0810/0820・0910。見本は H16、WebPier は R5）と JRSNAP・Aggre-SE（0711/0721）は後の段で本物の runner の受入として扱う。0400・0800・0900 は第1段の後に決める。
2. **合わない値の仕分け**：(1) WebPier の誤り → 直して決定にする（Example2 との整合も見る）、(2) 入力で表せない → その都度 owner が決める、(3) 基準・方法の違い → WebPier を正とし、差と理由を `tests/fixtures/example3/*_notes.md` に書き、期待値は独立の手計算。xfail は使わず、照合しない項目は注記で見えるようにする。
3. **置き場所**：入力は `tests/fixtures/inputs/example3.json`（schema 2 の完全な入力。`current.json` から書き換えない。`出典` にページと転記の方針）。期待値は `tests/fixtures/example3/<段階>.json` と `<段階>_notes.md`（Example2 と同じ約束：印字の値・桁・式の項の順、アプリの出力を見ない）。テストは `tests/<層>/test_example3_<段階>.py`、補助は層ごとに別の名前の `example3_*_support.py`。転記はアプリを動かす前に、実装を見ないサブエージェントで行う。
4. **列車荷重系の作用は本体の標準の荷重モデルを直す**（アドインにしない）。
5. **規定の版は R5**（断面照査の決定73とそろえる）。EA-17 の作用の特性値は R5（橋りょう編 5.4、Example4 I-38〜I-42）と H16（見本 Ⅰ-4-1〜4-3）で同じなので、特性値は見本と直接照合できる。版の違いは組合せ（R5 は 0.9D1+0.8D2、線路方向の列車配置3通り、使用性（損傷）⑩〜⑬、地震時の単線載荷）。
6. **EA-17 の規定一式**（車両名で切り替え、P-16 と Example2 は変えない。名前と出典付きの定数）：
   - 軸配置と後続の等分布 50 kN/m（Example4 図7.1.1、見本 図2.1.4・Ⅳ-1-2 の式 `{50×1.6×0.3＋170×(…)}/19.0×2/2＝500.5`）。EA-17 では `軸重`・`軸距`・`1両の長さ`・`編成数` を使わず、値があれば入力エラー。
   - 車両横荷重 0.15×170＝25.5 kN/軸、2.8/4.0/2.8 m の4軸（いまは 0.2P）。
   - 制動は列車荷重の 25%、始動は動輪軸重の 25%、大きい方（いまの (0.27＋1.00/Lv)·ΣR は R5 にも H16 にもないので削除。分類1）。
   - 地震時の列車 35 kN/m（`軸重.地震` は使わない）。
   - 入力に残す：`衝撃係数_単線終局`（桁の設計の結果）、列車速度、曲線半径など。桁の衝撃（複線 ×(1−Lb/200)、使用性 3/4）はいまの扱いで見本 表2.1.5 と一致（0.483→0.437、0.362・0.328、0.514→0.478）。
7. **橋脚く体の衝撃の低減を全車両で行う**（決定26 を廃止、決定27 の式と表を戻す）。i＝i0·{1−Ds/(L＋Du＋Ds)}：
   - 単線用・複線用の2つの比を両側の桁に共通に使う。L は両側の桁の列車荷重の特性値の和（ρf を掛けない。見本 1105.2／2210.4）、Du は両側の桁の D1＋D2（雪を含めない。6730.0）、Ds は柱下端までのく体（桁受け・はり・柱、浮力を引かない。1785.3）。
   - Ds/(L＋Du＋Ds) ≧ 0.9 なら i＝0。
   - 比は3桁（0.814・0.834）、i＝i0×比 も3桁（0.483×0.814＝0.393、使用性 0.362×0.814＝0.295）。
   - 0610/0620 の衝撃ケース（骨組・基礎とも柱下端の係数。見本 Ⅱ-2-7 と同じ安全側）に使う。0900 は桁座面なので i0 のまま。地震時は関係しない。
8. **作用の組合せは今の 16 の組を基本に残す**。見本の組合せとの対応表を作り、合わないものを2の仕分けにかける。片側載荷など具体的な不足は別の決定で足すか決める（組合せの一覧は案件の判断を含み、荷重モデル（決定70）に属する）。
9. **Example2 の後始末**：転記の JSON は変えない。`example2/*_notes.md` に「見本は橋脚の低減をしていない」を分類3として書き、影響するテストの期待値を独立の手計算に替え、見本と合わなくなる値を notes に挙げる。受入（FrameWeb、Capacita 0611/0621、基礎の照査、フーチング）は本物の runner で取り直す。地震時と 0900 は変わらない。
