#### 0720の計算結果契約

入口は `calculate_seismic_transverse(inputs: ReactionInput, reactions: Mapping, transverse: Mapping)`。入力は同一実行の現在入力・0600結果・正規0620結果だけとする。`schema_version=1`、`stage="0720"`、`direction="transverse"`、固有case/frame versionを持ち、入力スナップショット、単位、式の因子、丸め前値・表示値、適用済み震度、作用位置、ケース、出典、入力SHAを保存する。

必要なstage/schema/ケース識別・一意性・有限値・入力スナップショットの一致を検証する。SHAが提供されていれば相互一致を確認し、最終CLI成果物には実入力SHAを必須とする。結果を深くコピーして上流を変更しない。読み込むキーを限定し、ばね値・支持条件・旧組合せ・解析設定を公開frameへ混入させない。

| 作用 | 採用元と規約 |
|---|---|
| D1/D2/Wp/Sw2 | 正規0620の `dead_fixed` / `dead_additional` / `buoyancy_normal` / `snow_2_year`。D1のはり・柱重複控除、フーチング重心、分布荷重を維持。Wpの符号は保持し、上向き表示による再反転をしない。 |
| 上下線別列車 | 0600の `train.earthquake` × 当該側・支承のL1（下り）またはL2（上り）を1回。Nは丸め前行値を合計して2桁、Mは各行2桁丸め後を合計。負反力とC側固有アームを保持。衝撃・通常列車反力・使用性係数を使わない。 |
| EQ1 | 0600の直角case7、Kh=1適用。H=D1+D2+S2、M=H×hs。Single受渡し配列へ落とさず、0600のH/高さ/Mの精度を維持。 |
| EQL | 0600の直角case8、Kh=0.30適用済み。H=地震列車反力×0.30、M=H×(各側h1+h2+h3+列車地震重心高)。係数を再乗算しない。 |
| EQ2 | 現寸法・単位重量と0600重量からKh=1で計算。はり上・下、柱の分布強度を別々に保持。H1部は現在の重量と重心高による等価H/M、基礎は実重量/基礎単位重量×(基礎単位重量−排除土単位重量)。非矩形基礎を外接矩形体積へ置換しない。 |

EQ2はH2のはり上強度、H3の上端から下端への分布、H4の柱強度と基礎重心の集中力を区別して保持する。H3は原本p12の線形変化による表現とし、分布強度と集中力を異単位のまま加算しない。0.010 m分割後も柱区間の長さ・総作用を変えず、上部の形状表示部材へ自重を追加しない。はり下強度と柱強度が異なる場合も両者を保持する。

現入力の独立期待値（入力SHA `0a17f5301371fead6383eb00d315f6984bfd21c8580fe2e861a12d088e67f408`）:

- EQ1: H=6720+2370=9090 kN、M=19838+7267=27105 kN m。原本H=9080との差+10は入力出典欄に既記載。今回S2/hsを変更して消さない。
- EQL: H=96+48=144 kN、作用高さは両側5.35 m、M=770.40 kN m。
- はり上595.35、はり下297.68、柱297.68 kN/m、基礎1105.65 kN、現在の桁受けH=0。D1の基礎・D2の土重量等は上流Single精度を維持する。

#### 骨組と作用位置

正規0620の役割付き骨組を基にする。0.010 mはH4内のフーチング天端直上から分割し、H4>0.010、座標精度・鉛直接続を検証する。上部幾何高さは各側のh1+h2であり、hsとは別である。両側の上部高さが同じ座標なら共有節点、異なれば各側の役割を持つ別節点、ゼロならcap_topへ統合する。正の異なる高さを順に結ぶ形状表示部材とし、平均・最大値への置換、架空重量・作用・解析剛性を導入しない。既存H1分岐も保持する。

全追加後に節点を高さ降順、同高ではxと安定した元ID順、部材を中点高さ降順で採番する。全接続、役割、微小部材メタデータ、寸法、集中作用・分布作用の参照を更新する。分割した旧H4部材の荷重参照は、残部と微小部材の両方へ明示的に移す。

現在入力では8節点・7要素、全体13.050 m、橋脚本体10.300 m、上部2.750 m、柱残部4.890 mと微小部材0.010 m。微小部材は要素5（節点5–6）。これらは検証値でありモデル生成の定数にはしない。EQ1/EQLのH/Mはcap_top（現入力では節点2）に置く。上端節点へ移して既存モーメントに高さの効果を再加算しない。

共通化後の0710は結果値・frame metadata・例外条件・PDF表示を維持する。微小部材の原本上の非線形分類は出典情報としてのみ保持し、未実装の構成則・応答を計算済みとは示さない。
