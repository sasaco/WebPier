# 開始ボタンからの実行仕様

## 1. 入口

`input.xls` の `計算印刷` シートにあるフォームボタン `Button 1` の `OnAction` は `input.xls!計算スタートボタン_Click`。実体は標準モジュール `計算印刷` の同名Public Subである。

入力シートは表示名ではなく次のVBAコード名で参照する。

| 表示名 | コード名 |
|---|---|
| ご利用方法 | `InputSheet` |
| 上部構造 | `上部構造Sheet` |
| 上部工反力 | `上部工反力Sheet` |
| 下部構造 | `下部構造Sheet` |
| 地盤データ | `地盤データSheet` |
| 計算印刷 | `計算印刷Sheet` |

根拠: [計算印刷.bas](evidence/vba/input/計算印刷.bas) 12–32行、Excelのボタン割当・CodeName。

## 2. 分岐と処理順

1. `ThisWorkbook.Path` の親フォルダーを `Scripting.FileSystemObject.GetParentFolderName` で取得し、Public変数 `tmpPath` に入れる。
2. `下部構造Sheet.Range("基礎形式")`（`下部構造!C43`）を文字列として読み込む。
3. `Trim(基礎形式) = "直接基礎"` の場合だけ、次の4手続きを同期的に実行する。

| 順 | 手続き | 主な副作用・受渡し |
|---|---|---|
| 1 | `直接基礎計算.計算` | 0500へ入力転記、`Kv(1..2)`・`Ks(1..2)`・`Kr(1..2)`取得、保存・閉じる |
| 2 | `上部工反力.計算` | 0600へ転記、図形作成と移動荷重探索、結果配列取得、保存・閉じる |
| 3 | `線路荷重.計算` | 0610へ入力と1・2の結果を転記、保存・閉じる |
| 4 | `直角荷重.計算` | 0620へ入力と1・2の結果を転記、単線分担行の選択、保存・閉じる |

4. 上記以外の基礎形式では、`MsgBox "まだ、作成途中"` のみを実行する。
5. 分岐を抜けると、`MsgBox "計算が完了しました。"` を実行する。

途中で未処理の実行時エラーが発生すれば、5には到達しない。例外処理・後片付け用ハンドラー・ロールバックはない。後段で失敗しても、先行ブックの保存は戻らない。

## 3. ファイルの探索と既存ブックの扱い

4つのファイル名は `計算印刷` の文字列定数である。各処理は次のようにパスを構成する。

```vb
tmpPath = FSO.GetParentFolderName(ThisWorkbook.Path)
Set target = comon.OpenBook(tmpPath & BOOKNAME)
```

現物の配置なら `tmpPath` は `...\Example橋脚`。実コードは末尾の `\` を追加しないため、最初の引数は `...\Example橋脚0500_直接基礎.xls` となる。本来の配置 `...\Example橋脚\0500_直接基礎.xls` とは異なる。

`comon.OpenBook` は以下の順に処理する。

1. 引数から `FSO.GetFileName(FilePath)` でファイル名を取得。
2. Excelの全 `Workbooks` を走査し、`Workbooks(i).Name` と同じ名前があればそのブックを返す。
3. なければ `Workbooks.Open(FilePath)` で開く。

区切り文字欠落時は探索名も `Example橋脚0500_直接基礎.xls` となるため、正常な名前のブックを先に開いても回避できない。さらに、パスを直した場合でも開いているブックの照合は**フルパスではなく名前のみ**である。別フォルダーの同名ブックを再利用・更新する可能性がある。

再利用したブックも各手続きの最後で `.Save` と `.Close` する。ユーザーが手作業で開いていたかどうかは区別しない。

根拠: [comon.bas](evidence/vba/input/comon.bas) 2–24行、各 `計算` 手続き。

## 4. 0500と0600の内部順序

`直接基礎計算.計算`:

1. `B = B7+B8+B9`、`L = W7+W8+W9` を `Single` で求める。
2. 0500の `支持層` に地盤一覧表の指定10列と基礎幅を代入。
3. 同シートの6つのばね定義名を読む。
4. 保存して閉じる。

`上部工反力.計算`:

1. `Set死荷重反力`。
2. `Set橋脚自重` → `0600_上部工反力.xls!橋脚形状作成_Click`。
3. `Set列車荷重` → `0600_上部工反力.xls!test_Click`。
4. `Set線路荷重`。
5. `Set直角荷重` → `0600_上部工反力.xls!車両横荷重_Click`。
6. 自重、重心、列車・衝撃、地震列車、線路荷重10行、直角荷重8行をPublic変数へ読み込む。
7. 保存して閉じる。

数値計算の多くはセル数式に委ねている。開始マクロは `Application.Calculation` を設定せず、`Calculate` / `CalculateFull` も実行しない。自動計算が有効であることを暗黙に期待しており、手動計算では転記後に旧結果を読むおそれがある。

## 5. 0610と0620の内部順序

`線路荷重.計算` は `set骨組図` → `set荷重計算` → 保存・閉じる。

`直角荷重.計算` は `set骨組図` → `set荷重計算1` → `set荷重計算2` → 保存・閉じる。

0620の `set荷重計算1` は、支承位置と複線分担率を転記した後、単線分担率の候補を試す。この時点では、今回のD1/D2・列車荷重などを転記する `set荷重計算2` がまだ実行されていない。候補選択には前回保存状態の荷重が混ざりうる。判定式自体の問題も [不整合一覧](04-findings-and-next-design.md) に記載する。

## 6. ログインに関するブックイベント

開始ボタンの手続きとは別に、`input.xls` の `Workbook_Open` は `ご利用方法` シートの `username` / `userpass` を読み、片方でも空ならログインフォームを表示する。

`checkLogin` は入力文字列が実在するファイルパスなら、そのファイルの先頭行を読み込む。「ユーザーのチェックを行う」は作成中のコメントだけで、認証結果による計算許可・拒否は実装されていない。フォームのキャンセルはフォームを閉じるだけで、開始ボタン内に再認証はない。

`Workbook_BeforeClose` は入力がファイルパスでない場合に `ご利用方法!B19/B21` を空にする。今回このイベントは実行していない。仕様の根拠は抽出した `ThisWorkbook` / `LoginForm` / `InputSheet` のコードである。認証値は本wikiに収録しない。

## 7. この操作が出力しないもの

- 新しい結果ファイル名・出力先を指定する機能はない。既存の4冊を更新する。
- `input.xls` 自身への計算結果の書戻し・明示保存はない。
- メイン経路に `PrintOut`、PDF出力、CSV/JSON出力はない。モジュール名 `計算印刷` が印刷実行を意味するわけではない。
- 主経路のVBAにWeb API送信、外部EXE起動、柱やフーチングの断面照査呼出しはない。
- 複数案の探索、寸法・配筋の自動最適化、NG時の自動再設計はない。
