# 計算処理と結果表

この文書は既存VBA・セル数式を記述する。設計基準の正当性を新たに判断した仕様ではない。式中の定数は現行テンプレートの値である。全数式は [cell-formulas.json](evidence/cell-formulas.json)、セルに直接保存された係数・文字列は [constant-cells.json](evidence/constant-cells.json) に収録する。

## 1. 直接基礎の底面ばね

対象: `0500_直接基礎.xls` の `支持層`。

### 入力と支持層

入力の地盤表を `B12:AM22` へ転記し、`基礎幅B=U46`、`基礎幅L=Y46` を設定する。支持層は深度から自動選択せず、B列で名前が **「支持層」と完全一致する最初の行**をVLOOKUPする。

- 土質: `AK37=VLOOKUP("支持層",B12:L22,8,FALSE)`。
- Ed: `U43=VLOOKUP("支持層",B12:AI22,31,FALSE)`。
- 土質が「砂質土」なら係数区分1、「粘性土」なら3、それ以外は2。

N値・内部摩擦角・一軸圧縮強度は転記するが、以下の底面ばね式には使わない。深度・水位からの支持層判定や、支持層名の欠落・重複の検査もない。

### 数式

各 `ROUND` は、その行の中間値に対して実行する。

| 量 | 式 | セル |
|---|---|---|
| 底面積Av | `ROUND(B*L,3)` | AC46 |
| 換算幅Bv | `ROUND(SQRT(Av),3)` | AC45 |
| 土質係数a、指数p | 砂質土: 6.9,-0.5／粘性土: 3.8,-1／その他: 5.1,-0.75 | I37:I39、J49、Y49等 |
| 地盤修正係数ρ | 長期0.5、短期1.0 | L48、L51 |
| 鉛直反力係数kv | `ROUND(a*ρ*Ed*Bv^p,0)` | AC49、AC52 |
| 鉛直ばねKv | `ROUND(kv*Av,0)` | V63、V66 |
| せん断反力係数ks | `ROUND(kv/3,0)` | V79、V82 |
| せん断ばねKs | `ROUND(ks*Av,0)` | V94、V97 |
| 線路方向底面二次モーメントIvL | `ROUND(L*B^3/12,6)` | S110 |
| 線路方向回転ばねKrL | `ROUND(kv*IvL,0)` | U113、U116 |
| 直角方向底面二次モーメントIvC | `ROUND(B*L^3/12,6)` | S121 |
| 直角方向回転ばねKrC | `ROUND(kv*IvC,0)` | U124、U127 |

Kv/KsはkN/m、KrはkN·m/radの出力。Krの説明文にはkN/mという異なる表記も残るが、式は底面二次モーメントに反力係数を掛けている。

**VBAの出力契約は方向別になっていない。** `Kr長期/短期` はU124/U127を参照し、この直角方向の値を0610・0620の両方へ転記する。線路方向のU113/U116を読む処理はない。

0500に保存された入力は土質「安山岩」、Ed＝68600、B＝5.5、L＝7で、その他土質の係数を使っている。`input.xls` の支持層は「砂質土」であり、転記前後で係数が変わる。この0500保存値を現在の `input.xls` の期待結果にしてはいけない。

同梱シート `○地盤ばね (2)` には参照切れの式があり、主経路のばね読出しには使わない。支持力係数など固定値の残る欄も、この入口で地盤支持力の照査を実行する根拠にはならない。

## 2. 橋脚自重・土・浮力

対象: `0600_上部工反力.xls` の `橋脚自重`。

重量・偏心・重心の計算主体はセル数式。VBA `橋脚形状作成_Click` はB/W/H、土かぶり・水位を読み、Excel Shapesで形状・寸法・文字を描き直す処理である。

基本的に `N=ROUND(体積*単位体積重量,2)`、偏心・重心は体積一次モーメントを体積で除し、主に小数第3位まで丸める。直方体だけでなく傾斜部を合成する。梁の傾斜部体積はJ89、フーチングの傾斜部体積はJ142にあり、単純な外接直方体で置き換えない。

| 出力 | N | xL | xC | hG |
|---|---|---|---|---|
| 桁受け | X64 | X65 | X66 | X67 |
| はり | X92 | X93 | X94 | X95 |
| 柱 | X113 | X114 | X115 | X116 |
| フーチング | X146 | X147 | X148 | X149 |
| 上載土 | X181 | X182 | X183 | 読出しなし |
| 高水位 | X217 | X218 | X219 | 読出しなし |
| 平水位 | X251 | X252 | X253 | 読出しなし |
| 低水位 | X285 | X286 | X287 | 読出しなし |

水位荷重は浸水体積に定数 **-10kN/m³** を掛ける浮力で、負の鉛直力となる。体積ゼロのときの偏心にはIFによる保護がある。

hGの基準は部位・利用先ごとに確認する。たとえば `はりhG=X95` と集計表 `AA309` は異なり、後者は高さのオフセットを加える。Public配列は定義名が指す元の値を読む。すべてを基礎底面からの共通高さとして解釈してはならない。

描画は既存図形を消して再作成する。削除条件は指定範囲の上端・下端の間に図形のTopがあることを使っており、同じ高さにある別の図形も消しうる。

根拠: [橋脚自重Module.bas](evidence/vba/0600_上部工反力/橋脚自重Module.bas)、`橋脚自重` の数式・定義名。

## 3. 移動列車による支点反力

対象: [列車荷重Module.bas](evidence/vba/0600_上部工反力/列車荷重Module.bas)。入口 `test_Click`、主関数 `Get反力` → `Set列車配置` → `Get列車反力1` → `Get列車反力2` → `Get集中反力`。

### モデル

起点側桁の左張出し・支間・右張出しをL1/L2/L3、終点側をL4/L5/L6とする。起点桁の支点反力はRA/RB、終点桁はRC/RD。2つの桁をそれぞれ釣合いで解くモデルであり、連続梁・橋脚・基礎を一体にした剛性解析ではない。

車両長Lb、編成数n、軸距a1/a2、共通軸重pから軸を作る。入口ではa3＝0、等分布荷重W＝0。地震時の `軸重e` はこの移動荷重探索に入れない。

### 軸の生成

- a2>0: 1両4軸。`a4=Lb-a1-2*a2`。車両内の相対位置は `[0,a2,a2+a4,2*a2+a4]`、最後の軸から次車先頭軸までa1。
- a2<=0かつa1>0: 1両2軸。`a4=Lb-a1`。
- 総軸数は4nまたは2n。寸法の正値、a4>=0、nの上限などの明示検査はない。
- 関数内にはW>0の別処理が残るが、この開始経路では使用しない。

### 載荷候補と採用条件

1. 各軸を順に基準軸にする。
2. `[0,L1,L1+L2,L1+L2+L3,L1+L2+L3+L4,L1+L2+L3+L4+L5,ΣL]` の7位置へ合わせる。位置のループは末尾から先頭へ。
3. 配置座標は `Round(基準位置-(対象軸位置-基準軸位置),3)`。全長外の軸は除く。
4. 各候補のRA/RB/RC/RDを求め、**RB+RCが最大になる1つの載荷位置**を採用する。
5. 比較は `>`。同じ最大値では先に得た配置を維持する。

RBとRCを別々に最大化して足す処理ではない。探索中の最大値初期値は0で、すべての候補が0以下の場合の有効結果は保証されない。

### 反力の釣合い

起点桁全長をLa、終点桁全長をLc、全体座標をxとする。

- x<La: 起点桁に載荷し、RBへの寄与は `p*(x-L1)/L2`。
- x>La: `x'=Lc-(x-La)` へ反転し、RCへの寄与は `p*(x'-L6)/L5`。
- x=La: 起点桁端・終点桁端の寄与を比較し、大きい側に1回だけ載せる。同値はRC側。
- RA＝起点桁上の軸重合計−RB、RD＝終点桁上の軸重合計−RC。

主な数値型はVBA `Single`。配置座標の `Round` はVBAの関数で、ワークシートの `ROUND` と区別する。移植では各丸め段階と数値型を明示する。

### 出力

| 反力 | 計算式の説明文字列 | 数値 |
|---|---|---|
| RA | 列車荷重!J34（RAFormula） | AC34（RAValue） |
| RB | J36 | AC36 |
| RC | J38 | AC38 |
| RD | J40 | AC40 |

説明文字列はExcelに評価させる数式ではない。VBAが計算した数値を別セルへ書く。`Get反力` は数値計算と桁・軸配置の描画を一緒に行うため、描画の失敗も計算結果の返却に影響しうる。

一部下位関数は例外時に空配列や初期値を返す。上位には `RR(1)` などへのアクセス前に結果を検査する処理がない。

## 4. 列車荷重係数・衝撃・地震列車

`0600/列車荷重` の移動反力からセル数式で派生値を作る。

| 状態 | 列車反力 | 基礎となる衝撃係数 |
|---|---|---|
| 安全性・単線 | 移動反力×ρf破壊 | 入力i |
| 安全性・複線 | 安全性単線×列車本数 | `ROUND(i*(1-支間/200),3)` |
| 使用性・単線 | 移動反力×ρf使用 | `ROUND(i*3/4,3)` |
| 使用性・複線 | 使用性単線×列車本数 | `ROUND(安全性複線の係数*3/4,3)` |

列車本数は死荷重シート側からの参照であり、編成数（車両数）とは別の値。疲労用の表もあるが、開始ブックが読む最終列車反力12行には疲労ケースを含めない。

最終表は `T105:AE116`。T列がRB、X列がRC。各3行＝列車荷重、低減後の衝撃係数、衝撃荷重の順。105行から安全性単線、安全性複線、使用性単線、使用性複線の4組。

```text
低減後の衝撃係数
  = 基礎となる衝撃係数 × (1 - 橋脚上部重量 / (ケースのRB+RC + 死荷重合計 + 橋脚上部重量))
衝撃荷重 = ROUND(ケースの列車荷重 × 低減後の衝撃係数, 1)
```

橋脚上部重量は `U100=橋脚自重!X313`（桁受け・はり・柱）、死荷重合計は `U101=SUM(死荷重!N12:U12)`。

地震列車は別に `e*(L1+支間+L2)*0.5` を各桁へ適用する。`地震LB=AC57`、`地震LC=AC58`。この0.5は分担係数であり、ここで移動最大位置を探索しない。

### 単線候補の実装

コメント上は「D1+D2+Lの橋脚天端における偏心量が最も大きいケース」を選ぶ意図。

実装は次のとおり。

1. 今回の反力を転記する前にMD1/MD2を読む。
2. 入力の分担率4行を順にB/Cの単線分担率へ書く。
3. C側の分担率合計が正の場合のみ `ML+MD1+MD2` を比較する。B側合計は判定に残らない。
4. 初期値0に対して `>=` なら採用し、同値は後の候補を選ぶ。絶対値でも、軸力で除した偏心量でもない。
5. 最終候補を再転記する。候補なしの場合はkeyi＝0のままなので、範囲の直上行（入力ではD2）を読む。

さらに `ML=AD181` が分担率を使わない式の合計であり、候補の分担率だけを変えても比較値が変わらない。

水平8ケースはP275:AE282へ転記する。車両横・風・地震は `H=HB+HC`、`M=HB*zB+HC*zC` として集約する。遠心3ケースも表へ転記するが、下段には「直線区間のため遠心荷重は考慮しない」という固定記述があり、同様の集約・基本ケースはない。

荷重組合せには24行、28列の係数表がある。番号6～9が複線・下り・上りで重複するため、印字番号だけを一意なケースIDとしては使えない。下り・上りなど全状態の個別計算をこの入口が巡回する処理はない。

## 9. 丸め・型・係数の移植条件

- ワークシートの `ROUND` を段階ごとに維持する。最終値だけの丸めでは同じ数値にならないことがある。
- VBA `Single` への受渡し、VBA `Round`、Excelの数式演算を区別する。
- 入力由来とテンプレート定数を分ける。水の単位重量、震度係数、風圧、材料、荷重組合せ係数等は現行では別ブックのセルに埋め込まれている。
- 支承位置・偏心・作用高さの正負と基準面を明示する。
- 新プログラムが採用する設計式と、既存の不整合を含む比較用挙動を分ける。未実行の保存値一致だけを受入条件にしない。
