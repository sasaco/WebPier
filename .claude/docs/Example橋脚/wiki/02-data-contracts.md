# 入出力と転記の仕様

## 1. 表記と単位

`RB` / `RC` は起点側桁・終点側桁から対象橋脚へ作用する反力の組としてコードで扱われる。方向記号 `xL` は線路方向、`xC` は線路直角方向の偏心量、`hG` は重心高さ。自重表の添字は1始まりである。

距離・寸法はm、鉛直力・水平力・重量はkN、モーメントはkN·m、単位体積重量はkN/m³、変形係数と一軸圧縮強度はkN/m²、速度はkm/h、曲線半径はm、角度は度。個々の入力が無次元係数か分布荷重かは表の項目名・式に従う。`軸重e` はコード上の名前だが、地震列車の式では **kN/mの等分布荷重** として使う。

入力は名前付き範囲を経由し、結合セルの左上だけを指定間隔で読書きする。値の代入であり、入力セルの数式・書式をコピーする処理ではない。空欄を明示的に検証する処理はなく、空欄・文字列・Excelエラーの数値変換結果に依存する。

## 2. 下部構造

| `基礎形式` | 下部構造!C43 | 直接基礎／その他 | 開始分岐、0610/0620の骨組図 |
| `形状B1..B9` | 下部構造!F4:F12 | 側面方向の形状寸法 | 0600橋脚自重、0610/0620骨組図。B7+B8+B9が基礎幅B |
| `形状W1..W9` | 下部構造!N4:N12 | 正面方向の形状寸法 | 同上。W7+W8+W9が基礎幅L |
| `形状H1..H6` | 下部構造!V4:V9 | 各部高さ | 0600橋脚自重、0610/0620骨組図 |
| `形状df1/df2` | 下部構造!AJ4/AJ5 | 起点側・終点側土かぶり | 0600橋脚自重、0610/0620荷重計算 |
| `形状hw1..hw3` | 下部構造!AJ6:AJ8 | 高・平・低水位 | 同上 |
| `単位体積重量` | 下部構造!AZ20:BC25 | 梁・躯体、フーチング、杭、土の重量 | 相対行1・2・5・6だけを出力表の1・2・3・4行へコピー |

単位体積重量の実セルは、`AZ20`＝梁・躯体、`AZ21`＝フーチング、`AZ22/AZ23`＝杭の鉛直重量／慣性力、`AZ24`＝上載土、`AZ25`＝排除した土。杭の2行はこの経路で使わない。

保存入力例: B7/B8/B9＝0/5.5/0、W7/W8/W9＝0/7/0より基礎幅は5.5×7.0m。df1/df2＝2/2、H6＝2、梁・躯体とフーチングの単位体積重量は各24.5、上載土と排除土は各18。

斜角 `AR4`、タイプ `AR5`、杭種・施工条件・杭配置は入力画面に存在するが、この開始経路の転記対象になっていない。将来の入力スキーマで「画面にある」と「計算に反映される」を同一視しない。

## 3. 地盤データ

`地盤の一覧表` は `地盤データ!C5:AJ15`、11行×34列。11行すべてについて次の10列だけを0500の同名範囲へ写す。

| 相対列 | 入力列 | 項目 |
|---|---|---|
| 1 | C | 層番・層名 |
| 4 | F | 層厚 |
| 8 | J | 土質区分 |
| 12 | N | N値 |
| 15 | Q | 湿潤単位体積重量 |
| 19 | U | 水中単位体積重量 |
| 23 | Y | 内部摩擦角 |
| 25 | AA | 内部摩擦角の上限値 |
| 27 | AC | 一軸圧縮強度 |
| 31 | AG | 変形係数 |

表層厚 `F5` は `=下部構造!V9+下部構造!V8+MIN(下部構造!AJ4:AM5)`。現入力は4m。支持層の入力は2行目で、砂質土、N＝50、湿潤20、水中10、φ＝37、qu＝144、Ed＝68600。支持層の厚さ欄は空欄。

0500の計算でどの地盤行が使われるかはセル数式側で決まる。VBAは支持層を探索せず、全行転記と基礎幅設定だけを行う。

## 4. 上部構造

| 定義名 | 起点側／終点側の位置 | 0600での転記先・用途 |

| `L1`、`スパン`、`L2` | 上部構造!F5/I5/L5、F8/I8/L8 | 列車荷重。張出し長・支間と移動反力 |
| `i` | O5、O8 | 列車荷重。基準となる衝撃係数 |

| `f` | AP5、AP8 | 0610荷重計算へ直接転記。各々L2、L1を参照する式 |
| `車両長` | L38 | 列車荷重 |
| `軸距a1`、`軸距a2` | L39、L40 | 列車荷重 |

保存入力例: 起点側支間27m、終点側25.2m、車両長16.4m、軸距a1＝4m・a2＝2m、軸重p＝170kN、地震分布荷重e＝35kN/m、10両編成。支承は起点側「固定」、終点側「可動」、μは両方0.25。

## 5. 上部工死荷重・支承配置・分担率

| 定義名 | 入力範囲 |
|---|---|
| `D1A/D2A` | 上部工反力!K21/K22 |
| `D1B/D2B` | 上部工反力!O21:BB21 / O22:BB22 |
| `D1C/D2C` | 上部工反力!K57:AX57 / K58:AX58 |
| `D1D/D2D` | 上部工反力!BC57/BC58 |
| `ΣD1B/ΣD2B` | 上部工反力!BC21/BC22 |
| `ΣD1C/ΣD2C` | 上部工反力!AY57/AY58 |
| `支承位置B/C` | 上部工反力!O20:BB20 / K56:AX56 |
| `列車分担率B/C` | 上部工反力!O23:BB26 / K59:AX62 |

D1/D2はシート上で区別される死荷重の区分。マクロは区分を維持して転記する。B/C側には10支承分のスロットがあり、横40列のうち相対列1,5,9,…,37を読む。

0600の死荷重表は5支承×2領域で構成され、入力の10スロットを出力の `Areas(1)` と `Areas(2)` の相対列1,4,7,10,13へ並べる。A/D反力は1セルずつ転記する。

列車分担率の入力範囲は4行あるが、0600への転記は各側の先頭2行のみ。出力の3行目の複線分担率を読み、`複線分担率(1..10).RB/RC` に保存する。一方、0620の単線候補選択は入力の4行すべてをループする。この行数の相違は実装上の制約である。

## 6. 手続き間の結果データ

`Single` はVBA単精度実数。Excel数式の値をこれらのPublic変数に代入する時点で単精度に変換する。セル表示の丸めと同じ処理ではない。

| データ | 構造 | 取得元 |
|---|---|---|
| `Kv/Ks/Kr` | 各 `Single(1 To 2)`。1＝長期、2＝短期 | 0500支持層の長期・短期定義名 |
| 桁受け、はり、柱、フーチング | 各 `Single(1 To 4)`＝N,xL,xC,hG | 0600橋脚自重の同名定義名 |

## 7. 0610への出力

`骨組図` へB/W/H、長期・短期のKv/Ks/Kr、柱xLを `形状XL`、フーチングhGを `形状fg`、基礎形式を転記する。

`荷重計算` へ土かぶり・水位・4種の単位体積重量、起終点f、桁受け・はり・フーチングのN/xL、上載土・浮力相当のN/xL、桁受けhGを転記する。死荷重B/Cは支承別でなく `ΣD1B/ΣD1C/ΣD2B/ΣD2C` の合計値を使用する。

列車・衝撃は安全性に**複線**、使用性に**単線**を採用する。地震列車RB/RCと線路荷重10行もコピーする。これらの表から後続のセル数式が計算されるが、その結果を開始ブックへ戻すコードはない。

## 8. 0620への出力

`骨組図` へB/W/H、Kv/Ks/Kr、フーチングhG、基礎形式を転記する。偏心は0610の `形状XL` に代えて、柱xCから `形状XC` へ設定する。回転ばねは同じKr配列を用いる。

`荷重計算` は、支承位置・D1/D2の10支承スロットを横持ち入力から縦10行へ変換する。複線分担率はPublic配列から、単線分担率は入力候補から選択する。自重と偏心はN/xCを使い、列車・衝撃の安全性複線／使用性単線の選択は0610と同じ。

直角荷重8ケースについて、RB力・RB高さ・RC力・RC高さを相対列1/5/9/13へ写す。選択ロジックと計算式の問題は [04](04-findings-and-next-design.md) を参照。
