# 元Excelのセル再生をやめ、物理量で計算する

0600〜0710 は元Excelのセル番地で値を持つ「セル再生」の上に組まれており、0610の正規計算と0710は、監査用とされていた `legacy_audit` に実際には依存していた。ADR-0001 で正規経路は元Excelの誤りを直すと決めたため、セル番地のふりをした値を保つ意味がなくなった。そこで全段階を0620と同じく、意味のある名前の物理量（作用・体積・重心など）から計算する形にそろえ、旧セル再生の経路（`calculate_*_legacy`、`legacy_audit`、0600帳票側の式評価エンジン）と、それだけを検証する元Excelのセル照合テストを削除する。

## Consequences

- 元Excelから採取した値（`*_excel_oracle.json`、`reaction_round_oracle.json` など）はすべて廃止する。正規の値は、Example2 原資料から転記した期待値（0600も05/07のPDFから新たに転記する）と、実装を使わない独立の手計算だけで検証する。境界条件や非対称形状などの多条件の検証も、手計算の期待値として作り直す。
- 帳票が使うセル番地は、印刷位置の対応表として帳票側だけに置く。帳票に印刷する中間値はすべて計算器が出す。
