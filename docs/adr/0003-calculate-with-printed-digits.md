# 内部の値を印字桁に丸めて計算する

計算書は人間が印刷物の数値で検算する。そのため、計算書に印刷する値は内部でも印字桁に丸め、後続の計算はその丸めた値を使う。印刷された数値だけで、すべての式を電卓で再現できることを優先する。Double のまま計算して表示だけ丸める方式は、印刷物の検算と最終値が一致しないため採らない。元Excelの ROUND や VBA の Single 精度は、再現する目的では使わない（ADR-0001, ADR-0002）。

## Consequences

- 「表示丸めで計算値を変えない」という従来の原則は廃止する。表示の桁と計算の桁は同じものになる。
- 印字桁は計算器が値ごとに持ち、帳票はその桁のまま印刷する。帳票側で丸め直したり桁を探したりしない。桁は Example2 の計算書を基準に量の種類ごとに決める。
- 合計・積は印刷された部分の値から計算する（0.125 の3行は各 0.13、合計 0.39）。段階間の引継ぎも、前段の計算書に印刷された値で行う。
- 後続の計算に使う値は必ずどこかの計算書に印刷する。例外は移動荷重の載荷位置探索のような反復処理で、探索の内部は丸めず、採用した結果を印字桁に丸めて印刷し、以降はその値を使う。
- 丸めは四捨五入（0.5 は絶対値の大きい側）の1種類だけにする。
