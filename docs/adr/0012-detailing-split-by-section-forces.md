# 照査の前提は、断面力によらない構造細目を WebPier が、断面力を使う照査を断面照査のエンジンが受け持つ

照査の前提（構造細目、計算書 0400）のうち、配筋と寸法だけで決まる照査（鉄筋比、鉄筋のあき、せん断補強鉄筋の量と間隔、靭性率の上限など）は WebPier が入力だけから計算して判定する。断面力を使う照査（曲げひび割れ耐力 Mcrd、軸方向力の最大値から定まる最小鉄筋量 0.008Ac、最大鉄筋量 0.75pb、コンクリートの応力度 σc）は、断面照査のエンジン（Capacita）が断面照査の項目として計算し、0400 にはその節を参照する文だけを印刷する。Capacita には、RC標準第Ⅲ編 R5 の最小鉄筋量の照査に 0.008Ac と最大鉄筋量を足し、WebPier はその行8 に永久作用の断面力を渡す。見本 0400 は柱下端の N'd を自分で求めて照査しているが、WebPier は柱の断面力を持たない（骨組解析の結果は FEMPython のピックアップにあり、Capacita が取り込む。ADR-0006・0008）。0400 は入力だけで作れる出力項目とし、他の項目に依存させない（owner 2026-10-21）。

## Considered Options

- **0400 が骨組解析・断面照査の結果を読み、N'd・M'd を使う照査も WebPier で計算する**：0400 が 0611・0621・0810・0820・0910 に依存し、断面耐力の計算（Mcrd、釣合鉄筋比）が Capacita と WebPier に二重になる。採らない。
- **断面力を使う照査を 0400 から外し、何も書かない**：構造細目の一覧として欠け、どこで照査したか分からない。採らない。

## Consequences

- 断面照査の基準を H16 から R5 に切り替える（0611・0621・0810・0820・0910）。R5 の Capacita で最小鉄筋量・最大鉄筋量の節（`bending_rebar_amount`）を出し、0611・0621 では n.10 に置いて基礎の照査を n.11 に繰り下げる。
- 0400 の判定（`engineering_status`）は WebPier が判定する項目だけから決め、参照先の判定は含めない。
- 参照の文は、参照先の項目を選んだかどうかによらず常に印刷する。
- 場所打ち杭の 0400 は、杭の帯鉄筋量のせん断スパン比に 0500（SOIL-JR）の 1/β を使うので、出力項目 `ground_model` に依存する（決定98）。1/β は断面力ではないので、この ADR の分け方は保つ。杭頭反力の最大値から定まる最小鉄筋量は 0711・0721 で照査し、0400 は参照の文を置く。
- 鋼管ソイルセメント杭の 0400 は、結合部のずれ止めの段数を、両方向の静的非線形解析（0711・0721）の Aggre-SE のピックアップから読む杭頭の軸方向力（L2 の最大引張・L1 の最大圧縮）による杭頭反力に対する検討で決めるので、出力項目 `longitudinal_nonlinear_analysis`・`transverse_nonlinear_analysis` に依存する（決定123）。段数が 0400 の表・配筋図・位置の判定に効くため、場所打ち杭の杭頭反力の最大値（0711・0721 に頁を置き、0400 は参照の文）とは違い、検討の頁を 0400 に置く。断面耐力の計算を Capacita と二重にするものではないので、この ADR の分け方は保つ。
