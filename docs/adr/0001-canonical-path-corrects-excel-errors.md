# 正規の計算経路では元Excelの誤りを再現しない

WebPier は元Excel（0500〜0720のxlsと転記VBA）を基に作られたが、正規の計算経路は工学的に正しい式を使い、元Excelの誤りを再現しない。元式を意図的に残す箇所（**元式の互換動作**）は README の互換一覧に理由とともに列挙したものに限り、一覧にない元Excelとの差はすべて誤りとして修正し、「意図した修正」として記録する。

## Consequences

- 元Excelから採取した oracle の値は、修正した箇所では期待値として使えない。その箇所の期待値は新しい描画結果から作り直さず、独立に手計算した値へ置き換え、差の理由を fixture に注記する。
- 最初の適用例は 0600 はりハンチの重心位置（錐台重心を小さい面から測った距離を、上面からの距離として使っていた誤り）。
